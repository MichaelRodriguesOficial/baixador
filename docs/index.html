Como funciona

Você só cola os links. O resto acontece no servidor, mesmo com o navegador fechado.

  1. Cole os links

    Um por linha, quantos quiser. Se o compactado tiver senha, informe junto.

  2. Baixa um por vez

    Na ordem da lista. Se a conexão cair, tenta de novo e continua do ponto em que parou.

  3. Junta e descompacta

    Reconhece as partes de um mesmo arquivo, extrai tudo e apaga as partes para liberar espaço.

  4. Entrega o link

    Uma página com cada arquivo e um botão para baixar tudo em .zip. Depois do prazo, os arquivos são apagados.

O que ele abre

Arquivos que não estão compactados são entregues exatamente como vieram.

RAR em partes

Nos dois padrões de nome usados para volumes.

.part1.rar.part2.rar.rar.r00.r01

Partes numeradas

De qualquer tipo de arquivo, inclusive ISO e vídeo.

.7z.001.zip.001.iso.001.002

Compactados comuns

Em um arquivo só.

.zip.7z.rar.tar.gz.tgz.tar.xz.gz.bz2

As duas telas

O painel fica protegido por senha. A página do link é pública para quem tiver o endereço, e o endereço leva um código aleatório.

Instalar

Precisa de um servidor com Docker. A imagem é publicada para amd64 e arm64.

  1. Crie uma pasta e salve o docker-compose.yml ao lado.
  2. Troque a senha em APP_PASSWORD.
  3. Suba o container com docker compose up -d.
  4. Abra http://IP-DO-SERVIDOR:8080 e entre com admin e a senha.
services:
  baixador:
    image: ghcr.io/michaelrodriguesoficial/baixador:latest
    container_name: baixador
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      APP_USER: admin
      APP_PASSWORD: troque-esta-senha
      LINK_TTL_HOURS: "24"
      PUBLIC_URL: ""
      TZ: America/Sao_Paulo
    volumes:
      - ./data:/data
docker compose up -d
# atualizar para a versão mais nova
docker compose pull && docker compose up -d

Bom saber

Só links diretos

O link precisa iniciar o download ao ser aberto. Se ele abrir uma página com botão, contador ou captcha, o item fica marcado com erro.

Acesso de fora

Coloque atrás de um proxy reverso com HTTPS (Nginx, aaPanel, Traefik) e preencha PUBLIC_URL com o endereço público.

Onde ficam os arquivos

Tudo vai para a pasta ./data. Cada download tem um prazo e é apagado sozinho quando o prazo acaba.
